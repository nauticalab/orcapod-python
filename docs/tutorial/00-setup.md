# Part 0: Setup

About 10 minutes. At the end you have Orcapod installed, a check that it works, and the
workshop dataset on disk.

## Install

Orcapod needs Python 3.11 or newer. Create a fresh environment for the workshop so that
nothing else on your machine is affected.

With [uv](https://docs.astral.sh/uv/):

```bash
mkdir orcapod-workshop && cd orcapod-workshop
uv init
uv add orcapod
```

With `pip`:

```bash
mkdir orcapod-workshop && cd orcapod-workshop
python -m venv .venv
source .venv/bin/activate        # on Windows: .venv\Scripts\activate
pip install orcapod
```

If your workshop organiser asked you to install the development version instead, replace
`orcapod` with `git+https://github.com/nauticalab/orcapod-python.git` in either command.

The tutorial needs nothing beyond this. Orcapod already depends on `pandas`, `polars` and
`pyarrow`, which the samples use.

!!! note "Optional extras"
    `orcapod[ray]`, `orcapod[redis]`, `orcapod[postgresql]` and `orcapod[spiraldb]` add
    support for distributed execution and other storage backends, and `orcapod[torch]`
    installs PyTorch. None of them is used here.

    Drawing a pipeline graph ([Part 8](08-inspecting-and-tracing.md)) needs the Graphviz
    `dot` program on your `PATH`. It is optional; skip that one sample if you do not have it.

## Check your install

Save this as `check_install.py` and run it with `python check_install.py` (or
`uv run python check_install.py`):

```python
from orcapod import PipelineJob, function_pod
from orcapod.databases import InMemoryArrowDatabase
from orcapod.sources import DictSource


@function_pod(output_keys="doubled")
def double(value: int) -> int:
    return 2 * value


job = PipelineJob(name="install_check", database=InMemoryArrowDatabase())
with job:
    numbers = DictSource(
        data=[{"name": "a", "value": 1}, {"name": "b", "value": 2}],
        tag_columns=["name"],
    )
    double.pod(numbers, label="double")
job.run()

print(job.nodes["double"].as_table().sort_by("name").to_pylist())
# [{'name': 'a', 'doubled': 2}, {'name': 'b', 'doubled': 4}]
print("Orcapod is working.")
# Orcapod is working.
```

If you see the two lines above, you are ready. You do not need to understand the script yet;
every piece of it is introduced in the parts that follow.

### Messages you can ignore

Depending on what else is installed, you may see these on your screen. They are harmless.

- `UserWarning: Protobuf gencode version ... is exactly one major version older than the
  runtime version ...`, several times, when Orcapod is imported.
- `WARN deltalake_core::writer::stats] Skipping column ... because it's a binary field.`,
  many times, whenever results are written to an on-disk database (from
  [Part 5](05-pipeline-job.md) on).

## Get the dataset

The dataset is generated by one short script that uses only the Python standard library.
Download [`workshop_data.py`](workshop_data.py) into your working directory, or fetch it from
the command line:

```bash
curl -fO https://raw.githubusercontent.com/nauticalab/orcapod-python/main/docs/tutorial/workshop_data.py
```

Then run it:

```bash
python workshop_data.py
```

It prints `Wrote 27 files (... kB) to .../workshop_data` and creates the `workshop_data/`
directory described on the [tutorial front page](index.md#the-dataset). The data is the same
on every machine and every run, so your output will match these pages exactly.

Keep `workshop_data.py` in your working directory. Every part of the tutorial starts with
these two lines, which generate the data if it is missing and give you its location:

```python
from workshop_data import make_dataset

data_dir = make_dataset()
print(data_dir)
# workshop_data
print(sorted(p.name for p in data_dir.iterdir()))
# ['sessions', 'sessions.csv', 'subjects.csv', 'units.csv']
```

## Exercises

**1.** Open `workshop_data/subjects.csv` and `workshop_data/sessions.csv` in a text editor or
with `pandas.read_csv`. Which column or columns identify a row in each file?

??? success "Solution"
    In `subjects.csv`, `subject_id` alone identifies a row. In `sessions.csv` you need both
    `subject_id` and `session`: every mouse has a session called `s1`.

    ```python
    import pandas as pd

    sessions = pd.read_csv(data_dir / "sessions.csv")
    print(sessions.head(3))
    #   subject_id session        date  duration_s
    # 0   mouse_01      s1  2026-10-05        60.0
    # 1   mouse_01      s2  2026-10-12       120.0
    # 2   mouse_02      s1  2026-10-05        90.0
    print(sessions["subject_id"].is_unique, sessions[["subject_id", "session"]].duplicated().any())
    # False False
    ```

    Hold on to this idea. Orcapod calls these identifying columns *tags*, and Part 1 starts
    from them.

**2.** How many spikes are in `workshop_data/sessions/mouse_01_s1/spikes_imec0.csv`?

??? success "Solution"
    ```python
    import pandas as pd

    spikes = pd.read_csv(data_dir / "sessions" / "mouse_01_s1" / "spikes_imec0.csv")
    print(len(spikes))
    # 1736
    ```
