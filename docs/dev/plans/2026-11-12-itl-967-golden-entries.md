# ITL-967: every golden entry that moves relative to `main`

Generated by regenerating the golden values at `main` and at each merge commit of the
combined branch (ITL-910, ITL-944, ITL-954, ITL-945, ITL-942, ITL-935, in that order) and
comparing consecutive states. In an entry name, `<H>` stands for a hex digest and
`_vN` for a layout version, so that an entry whose name embeds a moved hash is matched
with itself; hash labels inside names are left out for the same reason.

Cause notation: `ITL-xxx(what)` where `what` is `digest` (the value's digest moved),
`label` (only the label text in front of the digest), `layout` (only a table layout
component inside the value) or `key` (the entry's name, which embeds a hash).
ITL-954 moves nothing. Entries that ITL-939 and ITL-943 added on `main` after the six branches
were cut have no per-merge states; their change under the hash step is listed as one step.
